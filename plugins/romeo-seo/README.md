# RomeoSEO skills for Claude Code

A collection of 50 free SEO, AI search, content and publishing skills. The skills provide workflows that can be used without a RomeoSEO account. Optional DataForSEO workflows require a separate account and may incur charges.

## Install

In Claude Code, add the Sigistry marketplace and install this plugin:

```text
/plugin marketplace add sigistry/marketplace
/plugin install romeo-seo@sigistry
```

This packaged snapshot is based on source commit `e2fed0c2e1c53840f0f04d0c6868d3931f2e7bea`; the plugin must be updated by pull request to this marketplace when the main skills change.

## Use

Ask for a task such as “Use seo-start-here to help me plan SEO for my website,” or select an individual skill such as `technical-seo-audit`. Each skill is documented in its own `skills/<name>/SKILL.md`. Read the applicable file and confirm any permissions, data transfers and charges before executing instructions.

No account or external tool is required to read the skills; some workflows can use Google Search Console, DataForSEO, user-selected publishing systems, or other services, subject to their own requirements.
