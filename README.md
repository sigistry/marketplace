# Sigistry Marketplace

Official plugin marketplace for Claude Code. Browse plugins at [sigistry.com](https://sigistry.com).

## Quick Start

Add marketplace:
```
/plugin marketplace add sigistry/marketplace
```

Install a plugin:
```
/plugin install code-auditor@sigistry
```
